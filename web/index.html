Simulation engine Working

The CPU itself, in C++ — 4,102 lines across 28 files.

  • 16-bit ALU with zero, carry, overflow, sign flags
  • 8 registers plus PC, IR, SP, MAR, MDR
  • Control unit producing a 14-line signal vector
  • Sparse memory — only written cells stored
  • Fetch → decode → execute → writeback

Assembler Working

Turns readable mnemonics into runnable instructions.

  • Two passes, with label resolution
  • Decimal, hexadecimal and binary literals
  • Comments, labels, flexible spacing
  • Errors name the exact line

Data structures Working

Hand-written — no std::stack, queue or map.

  • Stack — the CPU call stack
  • Circular queue — fetch buffer
  • Deque — 512-step rewind history
  • Hash table — three collision strategies
  • Linked list — symbol chains and logs

Graphics layer Working

Rasterisation written against a pixel buffer.

  • Bresenham line and circle
  • DDA line, kept for comparison
  • Scan-line, boundary and flood fill
  • Cohen–Sutherland clipping

  • Animated transfers with a drawn trail

  • Play, step, and step-backward
  • Six worked example programs

Data Structures

Stack
Is the CPU call stack. CALL pushes the return address; RET pops it back.
Circular queue
The fetch line. Wraps at the end instead of shifting everything.
Hash table
The symbol table — turns loop into line 3 instantly.
Deque
Holds 512 past steps so execution can run backwards.

Computer Organisation

ALU
A pure function: an operation and two values in, a result plus four flags out.
Control unit
Turns each instruction into fourteen on/off signals, every cycle.
Instruction cycle
Fetch, decode, execute, writeback — steppable one stage at a time.
Arithmetic
Add-and-shift multiply, printed as a step-by-step trace.

Tier 1 · do next

Cheap, high impact

  • Control-signal timing chart. The signals already exist — we only plot them.
  • Micro-stepping. Step inside one instruction, stage by stage.
  • Subroutines. CALL and RET, with the stack visible.
  • Hash-backed labels. Replaces the array scan.
Tier 2 · this term

Substantial additions

  • Pipelining. Watch a bubble appear when a hazard stalls the pipe.
  • Breakpoints. Stop when a register hits a value.
  • Cache simulation. Live hit and miss counts.
  • Wider arithmetic. 64-bit, hex↔BCD, strings.
Tier 3 · ambitious

If time allows

  • Two cores, one memory. Show a race condition live.
  • Two instruction sets. CISC and RISC compared on the same task.
  • Export to Verilog. Towards real hardware.

Scope. Limited on purpose to CO1 and CO2 of each subject. Labels are found by scanning an array rather than a hash table, because hashing is PL CO5. There is no call stack here, so CALL and RET are absent — stack and queue are PL CO3. There is no control-signal chart, which is COAL CO4. Shapes use graphics primitives rather than our own Bresenham routines, which are CGL CO3.
